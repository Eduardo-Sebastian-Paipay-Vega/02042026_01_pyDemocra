# Fase 4: UI / UX

Detalla el comportamiento de la interfaz de usuario, definición estratega de componentes visuales, mocking de datos y look & feel.

## Estructura
- **ui/**: Diagramas, activos reutilizables y prompts de UI.
- **componentes/**: Especificaciones, activos y prompts de componentes.
- **mocking/**: Pruebas y prompts de datos de mock.
- **look_and_feel/**: Documentación, activos y prompts visuales.
- **retroalimentacion/**: Reportes, evidencias y prompts de feedback de usuario.
