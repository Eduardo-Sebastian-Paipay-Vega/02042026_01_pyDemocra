# Fase 5: Arquitectura y Desarrollo

Agrupa la documentación de diseño de software a nivel de código, desarrollo guiado por pruebas (TDD) y optimización de rendimiento.

## Estructura
- **arquitectura/**: Decisiones arquitectónicas, diagramas y prompts.
- **backend/**: Especificaciones y prompts del backend.
- **tdd/**: Pruebas y prompts de Test-Driven Development.
- **tests_unitarios/**: Pruebas unitarias y prompts.
- **optimizacion/**: Reportes y prompts de optimización.
- **performance/**: Reportes y prompts de rendimiento.
