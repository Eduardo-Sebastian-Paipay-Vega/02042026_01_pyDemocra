# UI DESIGN RULE - CUSTOM SELECT COMPONENTS

NO NATIVE SELECTS: Queda estrictamente prohibido usar etiquetas `<select>` nativas de HTML o desplegables genéricos sin estilizar.

CUSTOM STYLING: Todos los menús desplegables de la aplicación deben ser componentes UI personalizados (Custom Select), manteniendo coherencia con el diseño visual de la app (Dark Mode, bordes redondeados, colores de hover y selección personalizados).

CONSISTENCY: Aplica esta regla en cualquier formulario o modal nuevo o existente.
