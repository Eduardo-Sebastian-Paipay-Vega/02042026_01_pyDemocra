## 2. Descripción funcional
* **Descripción:** Un banco de recursos (PDFs, PPTs, Enlaces, Interactivos) compartido por los docentes de toda la institución o red de instituciones. Su característica única es que el contenido no se califica por "Estrellas" (Subjetivo), sino por **Resultados Académicos Empíricos** (Objetivo): El sistema cruza las notas de los alumnos que consumieron el Recurso A vs el Recurso B, rankeando más alto el material que estadísticamente genera mejores notas.
* **Objetivo:** Promover la Inteligencia Colectiva Docente y el darwinismo de contenidos (el mejor material sobrevive, el inútil se hunde).
* **Alcance:** Buscador vectorial semántico, motor estadístico de impacto, interfaz de subida.
* **Actores:** Docente (Aportador/Consumidor), Sistema (Evaluador Estadístico).

## 3. Contexto
* **Precondiciones:** 
  1. RF-015 (Data Marts) debe estar calculando notas y consumo de material.
  2. Indexación semántica activada (pgvector) para búsquedas.
* **Disparador:** Búsqueda en la barra del repositorio ("Ejercicios de termodinámica").
* **Postcondiciones:** Resultados ordenados primariamente por `Empirical_Efficacy_Score` y secundariamente por `Semantic_Relevance`.

## 6. Flujo funcional
### Flujo principal (Búsqueda Vectorial + Impacto)
1. El docente ingresa su búsqueda en lenguaje natural.
2. El API de NestJS invoca al LLM (ej. text-embedding-3-small) para transformar el query en un Embedding (Vector de 1536 dimensiones).
3. Se ejecuta una consulta en PostgreSQL (usando `pgvector`) que combina la distancia del Coseno (Relevancia) con el *Efficacy Score* almacenado en el registro.
4. El motor estadístico (calculado asíncronamente en background cada semana) asignó un `efficacy_score` de 9.5 al "Video de Fracciones del Profesor X" porque el 90% de sus alumnos aprobaron.
5. El buscador multiplica (Relevancia Vectorial * Efficacy Score) y retorna la lista ordenada.
6. El docente visualiza el material top, y con un clic lo inyecta directamente en su propio sílabo (RF-001).

### Flujos alternativos
* **FA-01: Auto-Depuración:** Si un material (ej. PDF antiguo) acumula un `efficacy_score` negativo (Los alumnos que lo leen sistemáticamente desaprueban) o alto ratio de fatiga (RF-024, los alumnos se rinden leyéndolo), el sistema lo marca como `OBSOLETE` y lo oculta del motor de búsqueda predeterminado.

### Flujos de excepción
* **FE-01: Cold Start de Recursos Nuevos:** Si un recurso fue subido hoy, su `efficacy_score` es cero (Nadie ha tomado un examen usándolo). El motor inyecta un *Exploration Bonus* (Multi-Armed Bandit algorithm) dándole visibilidad artificial durante sus primeras 2 semanas para que acumule estadísticas justas antes de hundirlo.

## 8. Reglas de negocio
* **RN-001 (Correlación, no Causación):** El motor estadístico debe controlar variables externas. Si un PDF solo lo usan alumnos del "Salón de Genios" (percentil 99), su score estaría artificialmente inflado. Se debe aplicar normalización bayesiana en el script de agregación nocturno para medir el "Delta" (Mejora real) y no el valor absoluto.
* **RN-002 (Licenciamiento Cruzado):** Si el Tenant activa el "Global Pool", el recurso pasa a estar disponible para TODOS los colegios B2B de EDUCACION OS (Con atribución al docente creador).

## 9. Permisos y seguridad
* **Políticas RLS:** Los profesores pueden leer todo material público. Solo pueden modificar/borrar los creados por ellos (`UPDATE USING author_id = auth.uid()`).
* **Copyright Scanner:** Al subir un PDF, se ejecuta un hash check y análisis rápido de metadatos para evitar que un profesor suba el libro oficial de texto de "Santillana" o "Pearson" entero, violando DMCA y exponiendo a la empresa.

## 14. Criterios de aceptación (BDD)
* **CA-01: Búsqueda Semántica Eficiente**
  * *Given* que el docente busca "Mecánica Cuántica Básica"
  * *When* el query se ejecuta sin usar palabras exactas (Full Text Search fallaría)
  * *Then* `pgvector` debe devolver resultados relevantes sobre "Física subatómica" utilizando Cosine Distance (`<=>`), ordenados por el `efficacy_score`.
* **CA-02: Algoritmo de Cold Start**
  * *Given* un recurso de alta calidad recién subido
  * *When* se lista en los resultados compitiendo contra recursos de 3 años de antigüedad
  * *Then* el algoritmo debe aplicar el bono de "Freshness/Exploration" para que aparezca en el Top 5 temporalmente, permitiendo recolectar datos empíricos de alumnos.
