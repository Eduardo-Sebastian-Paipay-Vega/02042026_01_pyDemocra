# RF-F5-010: Gestión de Secciones y Horarios Académicos

## 1. Ficha Técnica
* **Código RF:** RF-F5-010
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Planificación Académica
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga por colegio)

## 2. Descripción Funcional
Gestionar la estructura física y temporal del colegio (Ej: 10-A, 10-B) asignando profesores, salones de clase físicos y definiendo el horario semanal.

## 3. Reglas de Negocio Vinculadas
* RN-01: Una sección no puede sobrepasar su `capacidad_maxima`.
* RN-02: El horario no puede permitir colisiones temporales de salón o de profesor.

## 4. Precondiciones
1. Los cursos, profesores e institutos deben existir.
2. El año escolar (grado) debe estar definido.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/academic/ScheduleBuilder`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/schedules/create`.
4. El sistema presenta el resultado esperado y renderiza el calendario.

## 6. Postcondiciones
* Registros guardados en tablas `secciones` y `horarios`.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/academic/TimetableGrid.tsx`
* **Lógica / Services:** `src/api/schedules.service.ts`
