# RF-F5-008: Motor de Gamificación Social

## 1. Ficha Técnica
* **Código RF:** RF-F5-008
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Estudiantes / Marketing
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga)

## 2. Descripción Funcional
Permitir a estudiantes y padres compartir logros, medallas (badges) y puntos obtenidos en redes sociales, midiendo el impacto de clics como canal de adquisición.

## 3. Reglas de Negocio Vinculadas
* RN-01: Debe generar una URL pública rastreable (`url_compartido`).
* RN-02: El sistema debe contar los `clicks_generados` y `conversiones` de prospectos.

## 4. Precondiciones
1. El estudiante debe haber desbloqueado un hito (Badge o Nivel).
2. El colegio debe tener habilitada la compartición social externa.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/gamification/ShareModal`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/gamification/share`.
4. El sistema presenta el resultado esperado (URL corta o Widget de Instagram).

## 6. Postcondiciones
* Registro insertado en la tabla `compartidos_logros` para Analytics.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/gamification/AchievementsPanel.tsx`
* **Lógica / Services:** `src/api/gamification.service.ts`
