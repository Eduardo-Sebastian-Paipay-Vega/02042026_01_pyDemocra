# RF-F5-006: Marketplace B2B de Productos Educativos

## 1. Ficha Técnica
* **Código RF:** RF-F5-006
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Marketplace / B2B
* **Impacto en Tenant Context:** Sí (Compras asociadas a la institución)

## 2. Descripción Funcional
Permitir a creadores (editoriales o colegios) listar productos educativos, y a las instituciones comprarlos mediante licencias con cálculo automatizado de comisiones.

## 3. Reglas de Negocio Vinculadas
* RN-01: El revenue split estándar es 25% plataforma, 75% creador (`comision_plataforma`).
* RN-02: Las ventas de licencias deben rastrear su expiración (`fecha_expiracion`).

## 4. Precondiciones
1. El producto debe estar en estado `publicado`.
2. La institución compradora debe tener un método de pago registrado.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/marketplace/Storefront`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/marketplace/purchase`.
4. El sistema presenta el resultado esperado y asigna las licencias.

## 6. Postcondiciones
* Registros insertados en `marketplace_ventas` calculando el `ingreso_creator`.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/marketplace/ProductDetails.tsx`
* **Lógica / Services:** `src/api/marketplace.service.ts`
