# RF-F5-005: Pasaportes Digitales Blockchain

## 1. Ficha Técnica
* **Código RF:** RF-F5-005
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Núcleo Central (Deep Tech)
* **Impacto en Tenant Context:** No (Global, abarca transferencias entre colegios)

## 2. Descripción Funcional
Generar un perfil académico y psicopedagógico (JSONB) inmutable para el estudiante que lo acompañará toda su vida escolar, validado contra una firma hash en Blockchain.

## 3. Reglas de Negocio Vinculadas
* RN-01: El `hash_blockchain` debe ser matemáticamente único.
* RN-02: El sistema debe permitir transferencias interinstitucionales registrando la historia.

## 4. Precondiciones
1. Historial de notas y reportes médicos existentes para ensamblar el JSONB.
2. Consentimiento de privacidad firmado por los padres (`privacidad_settings`).

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/blockchain/PassportView`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/passport/mint`.
4. El sistema presenta el resultado esperado y el hash público.

## 6. Postcondiciones
* Objeto inmutable guardado en la tabla `pasaportes_digitales`.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/blockchain/DigitalPassport.tsx`
* **Lógica / Services:** `src/api/blockchain.service.ts`
