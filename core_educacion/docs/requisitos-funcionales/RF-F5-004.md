# RF-F5-004: Planes de Matrícula y Suscripciones

## 1. Ficha Técnica
* **Código RF:** RF-F5-004
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Comercial / Finanzas
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga)

## 2. Descripción Funcional
Permitir a la institución crear planes de cobro recurrentes (mensual, anual) con diferentes tasas de interés por mora, automatizando la inscripción.

## 3. Reglas de Negocio Vinculadas
* RN-01: Debe permitir configurar el `numero_cuotas` (Ej: 1=anual, 12=mensual).
* RN-02: El plan debe contar con fechas de vigencia (`fecha_inicio_vigencia`).

## 4. Precondiciones
1. El `instituto_id` debe existir.
2. La pasarela de suscripciones recurrente (Stripe Billing) debe estar vinculada.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/finance/PlanBuilder`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/plans/create`.
4. El sistema presenta el resultado esperado.

## 6. Postcondiciones
* Registro creado en la tabla `planes_matricula`.

* **Vista / UI:** `src/features/finance/SubscriptionPlans.tsx`
* **Lógica / Services:** `src/api/subscriptions.service.ts`
