# RF-F5-001: Gestión de Calificaciones

## 1. Ficha Técnica
* **Código RF:** RF-F5-001
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Educación / Núcleo Central
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga por colegio)

## 2. Descripción Funcional
Registrar y almacenar el rendimiento numérico o cualitativo de los estudiantes sobre las lecciones de un curso, permitiendo a los profesores dejar retroalimentación textual.

## 3. Reglas de Negocio Vinculadas
* RN-01: La puntuación debe estar estrictamente entre 0 y 100.
* RN-02: Debe guardar la fecha exacta de evaluación (`fecha_evaluacion`).

## 4. Precondiciones
1. El `estudiante_id` y `leccion_id` deben existir previamente en la BD.
2. El `profesor_id` debe estar autorizado para el `curso_id` correspondiente.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/academic/GradesPanel`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/grades/assign`.
4. El sistema presenta el resultado esperado y recalcula el progreso.

## 6. Postcondiciones
* Registro insertado en la tabla `calificaciones` vinculado mediante FK.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/academic/GradesPanel.tsx`
* **Lógica / Services:** `src/api/grades.service.ts`
