# RF-F5-009: Sistema de Referidos B2B/B2C

## 1. Ficha Técnica
* **Código RF:** RF-F5-009
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Crecimiento (Growth) / Finanzas
* **Impacto en Tenant Context:** No (Puede cruzar múltiples institutos)

## 2. Descripción Funcional
Administrar el motor de referidos de la plataforma, recompensando con comisiones o descuentos a padres o instituciones que traigan nuevos clientes.

## 3. Reglas de Negocio Vinculadas
* RN-01: El estado de conversión solo pasa a `convertida` cuando el referido realiza su primer pago.
* RN-02: Se debe aplicar automáticamente la `comision_referidor` al ciclo de facturación.

## 4. Precondiciones
1. El referidor (padre_referidor_id) debe ser un usuario activo del sistema.
2. El link de referido debe estar correctamente tagueado (UTMs).

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/growth/ReferralDashboard`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/referrals/track`.
4. El sistema presenta el resultado esperado en el panel financiero del referidor.

## 6. Postcondiciones
* Inserción y actualización de la tabla `referrals_conversiones`.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/growth/RewardsPanel.tsx`
* **Lógica / Services:** `src/api/referrals.service.ts`
