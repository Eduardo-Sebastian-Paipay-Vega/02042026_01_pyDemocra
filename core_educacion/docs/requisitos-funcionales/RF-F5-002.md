# RF-F5-002: Gestión de Pagos y Facturación

## 1. Ficha Técnica
* **Código RF:** RF-F5-002
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Administrativo / Finanzas
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga)

## 2. Descripción Funcional
Procesar, registrar y rastrear el estado financiero de los estudiantes (matrículas, pensiones, extras), integrando recibos y transacciones de pasarelas externas (Stripe).

## 3. Reglas de Negocio Vinculadas
* RN-01: Cada pago debe tener un estado explícito (`pendiente`, `pagado`, `fallido`).
* RN-02: El `stripe_transaction_id` debe ser único en toda la base de datos (UNIQUE constraint).

## 4. Precondiciones
1. El estudiante debe estar matriculado (`estudiante_id` válido).
2. Se debe definir la fecha de vencimiento (`fecha_debido`).

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/finance/PaymentGateway`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/payments/process`.
4. El sistema presenta el resultado esperado y el link del `recibo_url`.

## 6. Postcondiciones
* Fila guardada en la tabla `pagos` con estado actualizado.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/finance/PaymentDashboard.tsx`
* **Lógica / Services:** `src/api/payments.service.ts`
