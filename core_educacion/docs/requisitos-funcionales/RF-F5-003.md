# RF-F5-003: Gestión Documental y Firmas

## 1. Ficha Técnica
* **Código RF:** RF-F5-003
* **Origen:** Carpeta FASE 5 (`FASE_5_BASE_DE_DATOS.md`)
* **Módulo Afectado:** Secretaría / Legal
* **Impacto en Tenant Context:** Sí (Requiere pantalla de carga)

## 2. Descripción Funcional
Administrar archivos PDFs y documentos legales de estudiantes, rastreando su almacenamiento (S3) y estados de firma digital (Docusign).

## 3. Reglas de Negocio Vinculadas
* RN-01: El estado del documento debe ser rastreable (`pendiente`, `firmado`, `rechazado`).
* RN-02: Se debe auditar la `fecha_creacion` y `fecha_firma`.

## 4. Precondiciones
1. El estudiante asociado existe en la BD.
2. El bucket S3 está configurado para la subida de archivos.

## 5. Flujo del Caso de Uso (Paso a Paso)
1. El usuario interactúa en la UI (`src/features/documents/UploadModal`).
2. Se resuelve/evalúa el `tenant_id` en el contexto.
3. Se invoca la función/servicio `api/documents/upload`.
4. El sistema presenta el resultado esperado y el `archivo_url`.

## 6. Postcondiciones
* Archivo guardado físicamente en S3 y fila creada en la tabla `documentos`.

## 7. Mapeo en Código Fuente
* **Vista / UI:** `src/features/documents/DocumentManager.tsx`
* **Lógica / Services:** `src/api/documents.service.ts`
